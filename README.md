# 日本一周クエスト 〜五教科の御朱印〜

日本列島を舞台に、中学5教科を学びながら進めるドット絵RPG。

- **表面**：北海道（理科）／東日本（社会）／西日本（国語）／九州（英語）／四国（数学）。御朱印を3つ集めると東京が解放され、五教科混合のラスボス戦になります。
- **裏面**：表面クリア後に開放。闇に沈んだ日本を、エリアをクリアするごとに明るく戻していきます。敵は色を反転させた姿になり、出題は発展問題のみ。
- **復習モード**：まちがえた問題が自動で記録され、正解できたら記録から消えます。

## 収録問題数

| 教科 | 基本（表面） | 発展（裏面） | 分野の割り振り |
|---|---|---|---|
| 国語 | 100 | 50 | 漢字35／語句25／文法20／古典15／読解5 |
| 数学 | 100 | 50 | 数と式・方程式・関数・図形・確率とデータを各20 |
| 理科 | 100 | 50 | 物理・化学・生物・地学を各25 |
| 社会 | 100 | 50 | 地理34／歴史33／公民33 |
| 英語 | 100 | 50 | 動詞時制・文の型・準動詞関係詞・比較受動助動詞・語彙前置詞を各20 |

合計 **750問**。全問に分野タグが入っています。

## 更新したのに反映されないとき

このアプリは端末に自分自身を保存して動く（オフラインで遊べる）ため、**ファイルを差し替えても
古い版が表示され続けることがあります**。Safariの履歴を消しても、保存された中身は消えません。

更新するときは、必ず次の手順を守ってください。

1. **`sw.js` の1行目の `CACHE` の数字を上げる**（`v2` → `v3`）。ここを上げないと、生徒の端末は
   古いファイルを使い続けます。**アイコンや問題を変えたら毎回必要です。**
2. アイコンを描き直したときは、**ファイル名も変える**（`icon-192-v2.png` → `icon-192-v3.png`）。
   同じファイル名のまま中身だけ変えても、端末は古い絵を握り続けます。名前を変えたら
   `index.html`・`manifest.webmanifest`・`sw.js` の3か所の参照も直します。

### それでも古いままのとき（iPad・iPhone）

ホーム画面に追加したアイコンは、**追加した時点の絵が焼き付いたまま**になります。履歴を消しても
変わりません。

1. ホーム画面のアイコンを長押しして削除する
2. 設定アプリ →「Safari」→「詳細」→「Webサイトデータ」→ 公開したサイトを探して削除する
3. Safariでサイトを開き直し、あらためて「ホーム画面に追加」する

2番を飛ばすと、保存されたファイルが残るため古いアイコンのままになります。

## ファイル構成

```
index.html              ゲーム本体
questions.js            問題データ（ここだけ編集すれば問題を追加・修正できます）
manifest.webmanifest    ホーム画面に追加するための設定
sw.js                   オフライン動作用
icons/                  アイコン各種（ファイル名に版数 v2 が入っています）
.nojekyll               GitHub Pages の変換を無効にする空ファイル
```

## GitHub Pages で公開する手順

1. GitHub で新しいリポジトリを作成します（例：`nihon-isshu-quest`）。公開設定は Public にします。
2. このフォルダの中身を**そのまま**リポジトリの直下に置きます。`index.html` がいちばん上の階層にあることが重要です。
3. リポジトリの **Settings → Pages** を開きます。
4. **Source** で `Deploy from a branch` を選び、Branch に `main`、フォルダに `/ (root)` を指定して Save します。
5. 1〜2分待つと `https://（ユーザー名）.github.io/（リポジトリ名）/` で公開されます。

### スマホやタブレットでアプリとして使う

公開したURLをスマホのブラウザで開き、

- iPhone・iPad：共有ボタン →「ホーム画面に追加」
- Android：メニュー →「アプリをインストール」または「ホーム画面に追加」

これでアイコンから起動でき、アドレスバーのない全画面で動きます。一度開いておけば、次回からは**通信なしでも遊べます**。

## 問題を追加・修正するとき

`questions.js` だけを編集します。形式は次のとおりです。

```javascript
{f:"分野名", q:"問題文", c:["正解","誤答","誤答","誤答"], a:0, e:"解説"}
```

- `c` の**先頭を正解**にしておきます（`a:0`）。出題時に選択肢は自動でシャッフルされます。
- `basic` が表面用、`adv` が裏面（発展）用です。
- 編集したら `sw.js` の `CACHE` の数字を上げてください（`v2` → `v3`）。上げないと、以前の版が端末に残ったままになります。

## 進行状況の保存について

クリア状況・最高正答率・まちがえた問題は、端末のブラウザに保存されます。端末や
ブラウザが変わると引き継がれません。記録はタイトル画面の「記録を消す」で初期化できます。

## 地図データの出典

地図は国土地理院「地球地図日本」を変換した [dataofjapan/land](https://github.com/dataofjapan/land)
を読み込んで、6ピクセル四方のマス目に焼き直して表示しています。非営利目的の場合は出典の明記が
必要です。ゲーム内の地図下に表記があります。営利目的で使う場合は、配布元への利用報告も必要です。

読み込めなかったときは、内蔵の簡易マップをドット化して表示します。失敗した理由は地図の下に
表示されるので、原因の切り分けに使えます。

## フォント

画面の文字は Google Fonts の DotGothic16 を使用しています。読み込めない環境では、
端末のゴシック体で表示されます。
